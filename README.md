# SARATHY-S-111925CB01048
🧮 Python Simple Calculator
A simple, beginner-friendly calculator built using Python. This command-line application performs basic arithmetic operations and handles common input errors.
📌 Features
➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Division
🛡️ Error handling for division by zero
🔄 Supports multiple calculations in one session
✅ Validates user input
🚪 Option to exit the program
🛠️ Technologies Used
Programming Language: Python 3
Interface: Command-Line Interface (CLI)
📂 Project Structure
python-simple-calculator/
├── simple_calculator.py
└── README.md
⚙️ Requirements
Python 3 installed on your computer
A terminal or command prompt
No external libraries are required.
🚀 Installation and Usage
Step 1: Clone the repository
git clone YOUR_REPOSITORY_URL
Replace YOUR_REPOSITORY_URL with your actual GitHub repository URL.
Step 2: Navigate to the project folder
cd python-simple-calculator
Step 3: Run the program
On Linux or macOS:
python3 simple_calculator.py
On Windows:
python simple_calculator.py
